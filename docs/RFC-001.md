## 摘要

本 RFC 提出五项改造，让 AI 长时记忆向真实人类记忆靠拢：**渐变遗忘、语义联想检索、自动归纳巩固、再巩固带追溯、记忆改变自身**。改造以人脑**互补学习系统（CLS）**为架构总纲，以神经科学与认知科学的既有机制为依据；同时明确划定边界——学习人类的遗忘与联想，保留机器的精确与追溯，不模仿人类的虚构与情绪染色。P0–P4 可在现有插件体系内闭环实现，P5 属研究前沿。

---

## 动机

当前 AI 记忆系统的本质是"档案室"：精确，但无遗忘、无联想、无成长。

| 现状缺陷 | 对应后果 |
|---|---|
| 遗忘是二进制的（active / archived） | 不重要信息永不衰减，沦为囤积 |
| 检索是关键词匹配（BM25） | 无语义联想，"记忆不会自己浮现" |
| 整理是手动压缩 | 只浓缩不归纳，不会长出高层规律 |
| 记忆不可更新，更新即覆盖 | 无追溯、无回滚 |
| 模型参数训练后冻结 | 经验无法改变自身，只会"更会查" |

**总体原则**（经作者与 AI 讨论确认）：

1. **学习人类的**：遗忘（作为卫生而非缺陷）、联想（记忆自己浮现）、归纳（从事例长出规律）；
2. **保留机器的**：精确（不虚构、不情绪染色）、追溯（一切改写可审计、可回滚）；
3. **分界诚实**：行为改变可工程实现；能力改变是研究前沿；第一人称体验无法复制。

## 总体架构：互补学习系统（CLS）

借鉴人脑的互补学习系统（McClelland, McNaughton & O'Reilly 1995）：

```
┌─────────────────────────────────────────────────────────┐
│                      皮层（慢，冻结）                      │
│              基座模型权重 —— 通用能力与泛化                  │
│              persona 蒸馏 = 睡眠期"皮层慢转移"              │
└───────────────────────────▲───────────────────────────────┘
                            │ 蒸馏 / 沉淀
┌───────────────────────────┴───────────────────────────────┐
│                    海马（快，细胞化）                        │
│          外部记忆库 —— 每条记忆独立存储，改 A 不伤 B          │
│                                                           │
│  生命周期：编码 → 巩固(归纳) → 提取(联想) → 再巩固(改动点)    │
│            → 遗忘(衰减)                                    │
└───────────────────────────────────────────────────────────┘
```

**核心论点**：灾难性遗忘的正解不是"把模型细胞化"，而是**事实与能力分开住**——事实住细胞（记忆库，改 A 不碰 B），能力住皮层（冻结权重），中间靠慢速蒸馏转移。

### 记忆分层结构

| 层 | 作用 | 理论对应 | 衰减速率 |
|---|---|---|---|
| 高层规律 | 提炼出的抽象规则 | 图式（Bartlett）/ 原型（Rosch）/ gist | 最慢 |
| 典型事例 | 规律的代表性实例 | 样例（exemplar，VAM 混合模型） | 慢 |
| 特殊点 | 事例与规律的差异（delta） | 图式例外槽（exception slots） | 中 |
| 笔记 | 原始事实的细节 | verbatim 痕迹（模糊痕迹理论） | 快 |

依据模糊痕迹理论：verbatim（笔记）比 gist（规律）衰减得更快——不同层用**不同衰减速率**，与人类一致。

## 详细设计

### 改造一：渐变遗忘（无思考难度，地基）

**激活度模型**：

```
激活度 = 重要度 × e^(-t/τ) × (1 + 检索加成)
```

- t = 距上次提取的时间；τ = 该层的遗忘时间常数（笔记 < 事实 < 规律）；
- 检索与注入按激活度排序；长期未被提取且激活度低于阈值 → 自动归档；
- **红线豁免**：importance ≥ 4 的记忆（安全相关规则）不参与衰减；
- 每次检索命中即强化（间隔重复效应）。

**参考算法**：艾宾浩斯遗忘曲线；SM-2 / SM-17 间隔重复（Anki / SuperMemo）；半衰期回归（Duolingo）。

**落地要点**：memories 表新增 `activation`、`last_retrieved_at`、`retrieval_count`、`decay_tau`（按层配置）；后台定时衰减 + 检索时即时强化。成本**低**，独立可先行。

### 改造二：语义联想检索（无思考难度，地基）

- **向量嵌入**：每条记忆存储 embedding；查询时把**当前对话上下文**编码为向量做余弦相似度召回；
- **混合检索**：BM25（精确关键词）+ 向量（语义联想），**RRF 融合**排序；
- **情境标签**：记忆条目附带话题链 / 时间 / 情绪等元数据，参与加权；
- **注入预算**：top-k + 相关性阈值，防止联想过度退化为噪音注入。

**技术选型**：向量存储 **sqlite-vec**（SQLite 原地扩展）或 BLOB + JS 余弦检索；嵌入模型 **bge-small-zh / bge-m3**（本地 ONNX）或 API 端点。目标效果：从"查档案"变为"联想唤起"——记忆不请自来。

### 改造三：自动归纳巩固（有思考难度，已定稿）

**聚类边界 = 相似度双阈值 × 出现频率 × 与既有规律的一致性**

| 人脑机制 | 含义 | 工程落地 |
|---|---|---|
| 模式分离 / 模式完成（DG / CA3） | 极似→合并；明显不同→分开；中间→保留各自条目、共享部分特征 | 相似度**双阈值** |
| 互补学习系统（CLS） | 抽象由**重复频率**驱动，而非单纯相似 | 多条独立条目重复指向同一模式才归纳 |
| 图式整合（Tse 2007） | 与规律一致→快吸收；冲突→记例外 | 冲突信息不强行合并，记入特殊点 |

**三层结构**（作者决策）：

> 「合并高层规律后，不同原始事实有的不同的特殊点记下就好，比如记特殊点为 1、2、3，原始事实 1 是典型事例 +1，原始事实 2 是典型事例 +2，至于典型事例则是多个原始事例与高层规律中间的位置，相当于一个能添加任意插件的白板，原始事实的更细节就靠笔记了。」

归纳完成后**原始事实不删除**，降权保留；特殊点以 delta 形式挂在典型事例上；细节下沉到笔记层（衰减更快）。

**抽象正确性：外置大脑验证**（作者决策）：

> 「抽象的正确性方面采用"外置大脑"，辅助作用，专门验证。」

验证协议三条：

1. **覆盖性**：每条原始事实都能从"规律 + 事例 + 特殊点"复原；复原不了 → 打回；
2. **一致性**：新抽象与记忆库既有条目做冲突检测，冲突不静默覆盖；
3. **可逆性**：从抽象出发能重构出典型事例；重构不出 → 抽象过度，降级。

**流程**：空闲触发（dream）→ 嵌入聚类 → 外置大脑验证（三查）→ 通过则生成规律层条目；打回则重试一次，再失败即放弃。

### 改造四：再巩固带追溯（有思考难度，已定稿）

**触发条件：预测误差门控**（作者决策：「使用个人觉得还是只在冲突时用。」）

依据再巩固文献（Nader 2000；Fernandez 2016）：**检索命中 + 新旧信息不一致（预测误差）才进入可改写窗口**；无冲突则原样重新稳定，不动。边界条件：

- 记忆越老、越强、被激活越多 → 改写门槛越高（importance 高则门槛高）；
- 改写是**组件级**的：预测误差发生在哪个组件，只改哪个组件。

**改写机制：追加改动点，不覆盖**（作者决策：「改写并非改写记忆，而是添加改动点，在原记忆后直接加要改动的点。」）

依据 Bouton 消退理论：大脑更新记忆时**原痕迹保留，新痕迹叠加**（消退 ≠ 擦除；自发恢复 / 再新 / 复现）。改动点结构：

```
改动点 {
  关联条目ID, 冲突组件, 旧值, 新值,
  冲突来源, 状态(候选/生效/失效), 复现次数
}
```

由此自动获得：**回滚** = 改动点置为失效（对应人类的自发恢复）；**追溯** = 原记忆永远可见；**版本竞争** = 新旧痕迹并存，看后续情境与复现频率谁占上风。

**分流规则**：同源冲突 → 追加改动点；异源冲突 → 新建条目（Gershman 潜在原因理论）。

**防漂移：外置大脑四查**（作者决策）：

1. **组件级检查**：改动点只许触碰冲突组件，不许顺带改无关字段；
2. **有来源**：新值必须能被冲突信息解释，diff 有出处；
3. **一致性**：生效后不与记忆库其他条目产生新冲突；
4. **打回带建议**：critic 输出 `reject + 修改建议`，重写一次；再不过即放弃。

**固化与回滚**：改动点复现 N 次才由"候选"转"生效"；置为失效即回滚（自发恢复机制），原记忆毫发无损。

### 改造五：记忆改变自身（研究前沿，路线已定）

**分界**：行为改变（偏好 / 风格 / 准则随经验变化）近路可达——persona 蒸馏 + 记忆注入；能力改变（学会新技能 / 新推理方式）需权重更新，研究前沿。

**能力改变的六大难点**：

1. **灾难性遗忘**：分布式表征下，一个权重参与无数知识，学新伤旧；EWC / 经验重放 / LoRA 只缓解不根治；
2. **统计悬殊**：个人经验 vs 万亿 token 训练语料，小样本更新 = 过拟合噪声；
3. **不可追溯回滚**：权重更新全局模糊、无 diff，与改造三、四的追加式原则冲突；
4. **对齐漂移**：安全对齐也是权重记忆，持续学习易丢；
5. **规模化**：一人一份权重成本爆炸；多人共用互相污染；
6. **连续性**：改权重 = 换演员，自我连续性无锚点。

**难点一专项结论：编码"细胞化"**：

- 大脑已有细胞化机制：齿状回（DG）模式分离、概念细胞、成年神经发生——稀疏局部编码防干扰；
- 工程三层次：**存储细胞化**（已实现：外部显式记忆）；**参数细胞化**（可行：per-domain LoRA 细胞、Product-Key Memory——旧细胞冻结，零遗忘）；**表征细胞化**（前沿：superposition 假说 + 稀疏自编码器 SAE 特征编辑，可审计可回滚）；
- 纯细胞化天花板：容量（组合爆炸）、泛化（隔离杀死迁移）、程序技能（函数装不进细胞）；
- **正解**：细胞化海马 + 分布式慢改皮层 = 本 RFC 的总体架构。

**现实路线（CLS 架构）**：

1. 改造一~四 = 建设海马（快学记忆）；
2. persona 蒸馏 = 睡眠期皮层转移 → 行为层成长；
3. 可选进阶（能力层，研究级）：事实类知识迁出权重（kNN / PKM / RAG）；新技能用 per-domain LoRA 细胞；记忆库作为**经验重放缓冲区**低频慢速微调；SAE 特征级改动点。

## 风险与取舍

| 风险 | 对策 |
|---|---|
| 联想过度 → 噪音注入 | 注入预算（top-k + 阈值） |
| 归纳幻觉 → 错误规律入库 | 外置大脑三查；两次不过放弃 |
| 改动点漂移 | 组件级限制 + 四查 + 复现 N 次固化 |
| 遗忘伤及重要记忆 | 红线豁免 + 分层衰减速率 |
| 权重更新伤及对齐 | P5+ 默认不碰权重；如需，低频 + 更新前后安全评估 + 整包回滚 |
| 验证成本 | 外置大脑仅在高价值环节触发（归纳、改动点），不全程介入 |

**总取舍原则**：宁可精确，不可虚构；一切改写可追溯、可回滚。

## 备选方案（Alternatives）

| 决策点 | 备选 | 选择 | 理由 |
|---|---|---|---|
| 遗忘 | 二进制删除 / 衰减 | 衰减 | 人类遗忘是连续的；二进制是囤积与误删之源 |
| 检索 | 纯关键词 / 纯向量 / 混合 | 混合（RRF） | 关键词保精确、向量补联想 |
| 改写 | 直接覆盖 / 事件溯源整条版本链 / 组件级改动点 | 组件级改动点 | 最贴近人类消退机制；回滚粒度更细、存储更省 |
| 验证 | 无验证 / 全自动验证 / 外置大脑 critic | critic 定点介入 | 全自动成本高；定点（归纳、改动点）性价比最高 |
| 能力层 | LoRA 微调 / 模型编辑（ROME）/ persona 蒸馏 | persona 蒸馏为近路 | API-only 环境无法改权重；蒸馏是唯一可落地的"成长" |

## 开放问题（求意见）

> 🙏 以下问题诚恳征求社区意见，任何一条的回答都可能直接改进本方案。

1. **衰减参数**：各层遗忘时间常数 τ 如何取值？是否有生产环境的经验数据（类似 Duolingo 半衰期回归的拟合方法）？
2. **注入预算**：联想检索的 top-k 与相关性阈值如何平衡"记忆浮现"与"噪音注入"？有没有成熟的评估指标？
3. **验证成本**：外置大脑（critic）的额外 LLM 调用成本与收益如何权衡？critic 是否可以用更小的模型？
4. **改动点粒度**：组件级更新的最小单元是字段、句子还是段落？粒度与漂移风险的关系？
5. **蒸馏频率与防锁死**：persona 蒸馏多久一次？如何避免 AI 偏好自我强化、拒绝被纠正？
6. **相似工作**：与 Mem0、Letta（MemGPT）、Zep、LangMem 相比，本方案遗漏了什么？哪些现成组件可以直接复用？
7. **API-only 约束**：当模型权重不在本地（如 DeepSeek API）时，"细胞化 / 能力层"是否有我们没有考虑到的替代路径？
8. **评估方法**：如何量化"类人化"的成效？遗忘曲线拟合度、检索命中率、归纳正确率、记忆漂移率——是否有更好的指标或已有基准？

2. 外置大脑验证：「抽象的正确性方面采用"外置大脑"，辅助作用，专门验证。」
3. 改写触发：「使用个人觉得还是只在冲突时用。」
4. 改动点机制：「改写并非改写记忆，而是添加改动点，在原记忆后直接加要改动的点。」
5. 审查机制：「一种是第三方审查（外置大脑进行改动前后的审查给出通过还是打回并提出 llm 改写时建议）。」
